# Конструктор приглашений — Next.js проект

Сервис самообслуживания: любой человек заходит на сайт, выбирает шаблон,
заполняет форму — и сразу получает свою ссылку на готовую страницу
приглашения (свадьба или день рождения). Без регистрации, без панели
администратора — как в примере `chungdoi.com/templates`.

Возможности: галерея шаблонов с фильтрами, экран-конверт, таймер до
события, место проведения с картой, RSVP-форма, кнопка «добавить в
календарь», фоновая музыка, анимации (Framer Motion).

## Как это устроено

- **`/`** — лендинг с превью нескольких шаблонов.
- **`/templates`** — галерея всех шаблонов с фильтром по типу события.
  Клик по шаблону ведёт в конструктор с уже выбранным оформлением.
- **`/create`** — форма создания приглашения. Данные и файлы уходят в
  базу данных и файловое хранилище, в ответ приходит уникальная ссылка.
- **`/i/[slug]`** — сама страница приглашения, которую видят гости.

Каждое созданное приглашение — отдельная запись в базе данных со своим
уникальным адресом (`slug`), а не отдельный сайт или IP-адрес. Все
приглашения живут на одном и том же домене.

## Нужна база данных и файловое хранилище

Без них форма создания приглашений работать не будет — данные ведь
должны куда-то сохраняться. Всё через Vercel, в несколько кликов, без
отдельных сервисов:

1. Зайдите в свой проект на [vercel.com](https://vercel.com) → вкладка
   **Storage**.
2. **Create → Postgres** → подключите к проекту (env-переменные
   добавятся автоматически).
3. Откройте вкладку **Query** у созданной базы и выполните содержимое
   файла `scripts/schema.sql` — это создаст таблицу `invites`.
4. **Create → Blob** → тоже подключите к проекту (для хранения фото и
   музыки, которые загружают пользователи).

### Локальная разработка

```bash
npm install
vercel env pull .env.local   # подтянет POSTGRES_URL и BLOB_READ_WRITE_TOKEN
npm run dev
```

Откройте http://localhost:3000.

Если Vercel CLI не установлен: `npm i -g vercel`, затем `vercel link`
(привяжет папку к вашему проекту на Vercel), после — `vercel env pull`.

## Деплой

1. Загрузите проект на GitHub (`git init`, `git add .`, `git commit`, `git push`).
2. На [vercel.com](https://vercel.com) → **New Project** → выберите репозиторий → **Deploy**.
3. Подключите Postgres и Blob как описано выше (если ещё не сделали).
4. Готово — форма на `/create` сразу начнёт создавать реальные приглашения.

## Редактирование шаблонов и оформления

Все 8 тем (4 свадебных + 4 на день рождения) — в `lib/themes.ts`:
`botanical`, `navy`, `blush`, `mono` (свадьба) и `confetti`, `space`,
`retro`, `balloons` (день рождения). Каждая тема — это палитра цветов,
шрифты и подпись стиля (`style`), которая показывается на карточке в
галерее `/templates`.

Чтобы добавить новую тему:
1. Добавьте `id` в тип `ThemeId` в `lib/types.ts`.
2. Добавьте палитру в `themes` и id в `themesByType` в `lib/themes.ts`.
3. При желании — добавьте декоративный SVG для темы в `components/Decorations.tsx`.

Декоративные элементы на обложке и на карточках шаблонов — это один и
тот же компонент `Decorations.tsx`, поэтому изменения темы сразу видны
и в галерее, и на самой странице приглашения.

## RSVP без сохранения ответов

Сейчас RSVP отправляется через WhatsApp/email/копирование текста — без
базы. Если захотите **сохранять** ответы гостей (видеть список
ответивших), добавьте ещё один API-роут (`app/api/rsvp/route.ts`) и
таблицу `rsvp_responses` — дайте знать, и я помогу это добавить.

## Структура проекта

```
app/
  page.tsx               — лендинг
  templates/page.tsx     — галерея шаблонов с фильтрами
  create/page.tsx        — конструктор (форма создания)
  i/[slug]/page.tsx      — страница конкретного приглашения
  api/invites/route.ts   — API: создать приглашение (запись в БД)
  api/upload/route.ts    — API: загрузить фото/музыку (Vercel Blob)
  layout.tsx             — общий layout, подключение шрифтов
  globals.css            — все стили и CSS-переменные тем
components/
  ConstructorForm.tsx    — форма создания приглашения
  TemplateCard.tsx       — карточка шаблона в галерее
  TemplateThumb.tsx       — живой мини-превью оформления
  InviteExperience.tsx    — вся визуальная логика самого приглашения
  Cover.tsx, Hero.tsx, Countdown.tsx, Venue.tsx, NoteSection.tsx,
  Rsvp.tsx, CalendarButton.tsx, ShareSection.tsx, Closing.tsx,
  MusicPlayer.tsx, Decorations.tsx  — отдельные блоки приглашения
lib/
  themes.ts         — палитры, шрифты и стили всех тем
  types.ts          — типы данных
  slug.ts           — генерация ссылки из имён
  mapRowToConfig.ts — превращает строку из базы в данные для рендера
scripts/
  schema.sql — SQL для создания таблицы invites
```
